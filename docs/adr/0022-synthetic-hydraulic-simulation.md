# ADR 0022: Synthetic hydraulic simulation fallback

- **Status:** Accepted for a synthetic workflow and numerical benchmark only; not engineering-grade.
- **Context:** The available world fixture defines asset relationships/capacity hints but has no calibrated pipe geometry, pump curves, source levels or tank data. WNTR is not installed and no verified hydraulic input model is present. The legacy `SimulationRequest` is a particle-body schema and cannot describe a hydraulic network.
- **Decision:** Keep the legacy wire contract and endpoint unchanged. Add typed Pydantic `/v1/simulations/scenarios` endpoints for the synthetic workflow, published by runtime OpenAPI. The independent fallback is a bounded steady-state linear head-loss network with fixed synthetic source heads, demand withdrawals, and link resistance. It solves nodal continuity by Gaussian elimination and rejects malformed/disconnected/singular networks and residuals above `1e-9 m3/h`. Use one immutable topology-bound snapshot and fixed seed across baseline, virtual-backup and resistance variants.
- **Model:** For unknown-head nodes, solve `Σ_j (H_i-H_j)/R_ij = -D_i`, where `H` is gauge head in kPa, `R` is synthetic kPa/(m3/h), and `D` is demand in m3/h. Signed link flow is `(H_from-H_to)/R`. Repeat steady state for 60 one-minute steps (one synthetic hour). Energy is a proxy from fixed source head times injected flow divided by 3600 and an assumed 0.70 efficiency. Downtime proxy is one simulated hour whenever service pressure is below 200 kPa or demand exceeds the synthetic 6 m3/h capacity.
- **Approval/application:** A proposal binds exact allowlisted virtual action JSON and snapshot SHA-256. Owner/admin approval is required from a distinct actor. A requester can then consume once to run only the simulator reducer. No plant/PLC/SCADA or actuator client exists. All transitions are tenant/site-scoped and audited.
- **Persistence:** Additive migration 009 stores run snapshot/result hashes, state, approvals and audit. Existing data is not rewritten. Readiness requires migration 009; no automatic downgrade is provided. Existing generic simulation schema remains unchanged, so clients should use the new scenario API contract instead of sending hydraulic inputs through the particle-body endpoint.
- **Consequences/risks:** Outputs demonstrate reproducible math and governance flow, not real infrastructure accuracy. Missing pump curves, tank levels, friction equations, elevation, transients, calibration and uncertainty intervals make output inappropriate for engineering/operations decisions. Topology digest proves which canonical asset graph was referenced, but the compact hydraulic network is a separate fictional model.
