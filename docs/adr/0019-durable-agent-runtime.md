# ADR-0019: Durable multi-agent runtime boundary

- **Status:** Provisional; execution adapter gate remains open.
- **Context:** The phase asks for a 13-role typed graph, durable Temporal orchestration, leased foreground client inference, durable trace and tenant-scoped controls. The authoritative master-spec and contract reference prompts are absent from this checkout. Temporal SDK was not available and uv could not resolve/use the locked project interpreter in this environment.
- **Decision:** Define the named graph and strict bounded outputs in the API source; persist tenant-scoped run, per-role, attempt, event, and client-task rows via additive migration 006. Deterministic roles are labeled separately from client-model roles. Run creation is idempotent by tenant key. API exposes role registry, run creation/list/detail and explicit control endpoints. Control calls fail closed with 503 until Temporal signaling is configured; creating a run persists it as `queued`, without claiming it executes. No mock executor or server-side Firebase client imitation is used.
- **Security:** Tenant membership and site scope gate create/read/control. Request rejects obvious restricted-byte fields and caps serialized input at 64 KiB. This is a narrow guard, not a replacement for the missing policy lease/classification pipeline. Persisted run inputs need retention and field-level classification policy before production.
- **Migration impact:** New additive SQL migration `006_agent_runtime.sql` adds five tables and run uniqueness constraints. Existing rows are unaffected. Readiness now expects migration 006; deployments must apply it before becoming ready. No shared wire contract version was changed. IndexedDB is unchanged.
- **Consequences / open gates:** Temporal workflows/activities, NATS triggers, worker registration, durable client-task claim/heartbeat/result fencing, Firebase client attempt, and real Temporal replay/crash checks are not implemented or verified. Temporal dependency/lockfile is unchanged. Client-task table is reserved schema only. Actual authoritative execution must not be enabled until these gates and privacy policy contracts are implemented.
