# ADR-0024: Mission Control and incident workspace

- **Status:** Accepted for the synthetic operational fixture; production acceptance remains partial.
- **Context:** Existing APIs expose tenant/site-authorized world snapshots, bounded telemetry, canonical event cursors, agent run projections, simulation approvals and registered device identities. Mission Control needs a coherent, fresh site view without inventing operational values.
- **Decision:** `/mission` composes these existing API projections. It reconciles from the site snapshot at session load/reconnect and reads only the authorized event cursor on a bounded timer; relevant events trigger a projection refresh. Tenant/site changes hide old-scope data. Incident details use stable incident IDs and show canonical source state, linked assets, bounded event history, persisted investigations, run traces and existing simulation approval entry points. `/field` aliases the existing FieldRelay page. Telemetry permits bounded ranges, local pagination of the bounded API result, threshold markers, missingness reporting and explicitly synthetic CSV export. Demo reset is a dedicated authenticated API operation restricted to the `demo-nexus` owner, exact confirmation, `APP_ENV=local`, and loopback/local database host.
- **Consequences:** No shared wire schema, persisted application schema, or IndexedDB schema changed. `/v1/demo/reset` deletes the local demo tenant using the existing reset guard; it has no automatic rollback or reseed. Event history visible in incident details is capped at 2,500 fetched events and 100 displayed. Mission refreshes multiple existing API resources after observed activity; this is intentionally bounded but can be chatty during continuous event flow.
- **Limitations:** World and telemetry data remain synthetic. Agent runs are queued because the Temporal worker is not configured. Registered peer inventory does not indicate an active connection. Field evidence file bytes remain in browser memory and are not included in the safe outbox; offline inference is still disabled without a policy lease. No browser, Postgres, or reset end-to-end acceptance was run in this environment.
- **References:** Required `prompts/reference/master-spec.md`, `contracts.md` and `official-requirements.md` were absent during implementation. This ADR is therefore provisional against those references.
