# ADR-0016: Adaptive Firebase hybrid inference runtime

- **Status:** Accepted for the browser lab; live device and App Check gates remain open (2026-11-15).
- **Context:** Phase 08 needs a typed adapter over Firebase AI Logic, privacy-aware mode choice, real source reporting, and bounded task handling. Product role definitions and official project references are absent.
- **Decision:** Pin the adapter to the existing Firebase Web SDK 13.3.0 and its `getAI`, `GoogleAIBackend`, `getGenerativeModel`, `InferenceMode`, `initializeDeviceModel`, inline image parts, and SDK response `inferenceSource`. ONLY_ON_DEVICE does not fetch Remote Config, uses no cloud fallback of its own, and fails when its capability/model path is unavailable. Other modes preserve the Firebase SDK's own fallback behavior. The UI reports only SDK response source, with missing metadata as UNKNOWN; test fixture provider can emit MOCK only.
- **Data and privacy:** Browser task input is a fixed synthetic public fixture. Cloud-capable modes require explicit consent. Restricted classifications are rejected, unsupported modalities fail before invocation, no arbitrary tools or conversation history are supplied, and responses are locally schema checked with at most one bounded repair. Optional browser audit keeps metadata only. No response/prompt content is persisted.
- **Task scheduling:** The package provides a typed local `TaskTransport` seam, five-minute lab lease, bounded exponential submission retries, cancellation and foreground checks. Server lease acquisition and result submission are not implemented; the browser route must not claim either operation is remote.
- **Consequences / limitations:** Source identity depends on SDK `inferenceSource`; UI mode is not proof. ONLY_ON_DEVICE/offline and App Check enforcement need real device/project evidence. Cloud vs local model output and support may differ. Product role registry remains unresolved; `fixture_qa` is a provisional fixture role only.
- **Migration impact:** None to shared contract versions or persisted server schema. Workspace adds `@nexus-titan/hybrid-web` dependency. pnpm importer updates await frozen-lock verification due registry access failure.
- **Verification:** Nine direct Node policy tests passed. Package lint/typecheck, web build and new-adapter live cloud/local/App Check requests were not run in this phase because registry access was unavailable and current hardware is not eligible for device inference.
