# Contributing

1. Read `AGENTS.md`, `docs/BUILD_STATE.md`, and the available project references before changing code.
2. Keep changes focused and update shared contracts and relevant ADRs when architecture or wire formats change.
3. Run the relevant checks from the root README. Never mark an unrun check green.
4. Save sanitized command output under `docs/evidence/` and record actual exit codes, skipped checks, blockers, and migration impact in `docs/BUILD_STATE.md`.
5. Do not add credentials, private data, fake success endpoints, or generated mobile binaries.
